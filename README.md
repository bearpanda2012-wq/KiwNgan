# KiwNgan คิวงาน

ระบบคิวงานสำหรับทีมออกแบบและงาน CAD/CAM เปิดได้ทั้งมือถือและคอมพิวเตอร์ ติดตั้งลงหน้าจอมือถือได้เหมือนแอป ข้อมูลทั้งหมดเก็บใน Google Sheet ของทีมเอง

## ความสามารถ

- **ทีมออกแบบดีไซน์ (ฝ่ายแบบ)** (v2.85 / backend 1.41) หน้าเพิ่มงานเลือกทีม "CAD / CAM" หรือ "ออกแบบดีไซน์" · ทีมออกแบบเลือกประเภท 5 แบบ: Façade (3 วันทำการ) · คอนโด/บ้าน (6) · รีโนเวทบ้าน (6 · นัดเข้าหน้างาน 3 ช่วง) · Jobshop (2 · เสร็จแล้วเข้ารอผลิต) · Catalog/สินค้าใหม่ (Wallix, Wallterior, EPS, Forms Ceramic, ตัวโชว์ · งานประจำสร้างรอบถัดไปได้) · ช่องกรอกเฉพาะประเภท (พื้นที่ วัสดุ งบ สไตล์ Pattern ที่อยู่/แผนที่ นัดสำรวจ/วัดพื้นที่) · ขั้นตอนตามหน้าที่งานขึ้นเป็นเช็กลิสต์ · กำหนดส่ง มาตรฐาน / เลือกวันเอง / ไม่กำหนด · เลข Job เว้นว่างได้ (ตั้งเลขชั่วคราว DSyymm-nnn) และใช้เลขเดียวกับงาน CAD/CAM ได้ · รายการเฟอร์นิเจอร์ + คัดลอกส่งจัดซื้อ · การ์ดมีป้ายนัดหน้างานวันนี้/พรุ่งนี้ · Façade กด "เปิด PO" สร้างงานไฟล์ผลิตให้ทีม CAD/CAM · นัดหน้างานขึ้นในสรุปงานเช้า (หัวข้อ 📍) และแจ้งเตือน 08:00 ถึงผู้รับผิดชอบ+ผู้ร่วมทำงาน ทั้งนัดวันนี้และวันทำงานถัดไป (v2.85.1 / backend 1.42)
- **หน้า Express ใช้ง่ายขึ้น** (v2.92–2.94) การ์ดสรุปสีพาสเทล กดแล้วเลื่อนไปที่รายการ · แท็บแบบสไลด์ · ชิปกลุ่มมีสีประจำ · ค้นหาบอกหมวดของผลที่เจอ · พิมพ์ไม่เปิดหน้าต่างใหม่ · แถบรายการที่เลือกลอยติดขอบล่าง · กดแถบซ้ายของแถว = ติ๊กเลือก
- **ความลื่นบนมือถือ/แท็บเล็ต/คอมรุ่นเก่า** (v2.98) แอนิเมชันวน (เรืองแสง แถบวิ่ง จุดเต้น) เล่นสักครู่หลังเข้าหน้าแล้วหยุดเอง (เดิมวนตลอดจน CPU ทำงานหนักแม้ไม่ได้แตะจอ) · เครื่องช้าเข้าโหมดประหยัดอัตโนมัติ (iOS/Safari ก่อน 15, Android เก่า, CPU 2 คอร์, RAM น้อย หรือใช้แล้วกระตุกจริง) เล่นรอบเดียว ไม่เบลอกระจก · ตั้ง "ภาพเคลื่อนไหว: เต็ม" ได้ถ้าอยากให้วนตลอด · หน้าเลื่อนที่รากแทน body (เลื่อนลื่นขึ้น เปลี่ยนหน้าแล้วขึ้นบนสุดถูกต้อง) · พื้นหลังไม่วาดใหม่ทุกเฟรมตอนเลื่อน · ข้อความใหม่ไม่วาดทั้งหน้า · แอปอยู่เบื้องหลังไม่วาด · Safari รุ่นเก่าเปิดไฟล์ได้ (ตัด regex แบบใหม่) · วัดผลด้วย `tests/perf.mjs`
- **ดูแล้วกี่คน / อ่านแล้วกี่คน** (v2.97 / backend 1.47) คลังความรู้: การ์ดมีไอคอนตาบอกจำนวนคนเปิดดู · ในเรื่องขึ้น "ดูแล้ว N คน" กด "ดูรายชื่อ" เห็นว่าใครดูเมื่อไร (หน้า Sale เห็นแค่จำนวน) · นับคนละ 1 ครั้ง · Sale ลิงก์รายคนนับเป็นชื่อ Sale ลิงก์รวมนับต่อเครื่อง · แชต: ข้อความของเราขึ้น "✓ อ่านแล้ว N" (แชตส่วนตัวขึ้น "อ่านแล้ว") แตะดูชื่อคนอ่าน · ข้อความคนอื่นในห้องทีมมีไอคอนตา + จำนวน · คำขอความช่วยเหลือก็บอกด้วย · ชื่อแอดมินยังซ่อนตามเดิม
- **งานที่ส่งแล้วค้างไว้ 20 วัน** (v2.96.2) ภาพรวมบริษัทและบอร์ดผลิตแสดงงานที่ส่งแล้ว 20 วัน (เดิม 7) นับแยกแต่ละงานจากวันที่กดส่งแล้ว · เก่ากว่านั้นค้นด้วยเลข Job ได้เสมอ · หน้า Sale การ์ด "เลยกำหนด" นับทั้งฝ่ายแบบและฝ่ายผลิต บอกแยกจำนวน (v2.96.1)
- **รูปตัวอย่างเล็กหน้า Sale** (v2.96) แถวงานในหน้า Sale ทั้งแบบติดตามงานและแบบตาราง มีรูปตัวอย่างข้างเลข Job (มีหลายรูปมีตัวเลขบอก) กดรูป = ดูรูปเต็มจอเลื่อนดูทุกรูปของงานนั้น ไม่เปิดรายละเอียด · ป้าย 📷 จำนวนรูปเดิมเปลี่ยนเป็นรูปตัวอย่างแทน
- **รูปตัวอย่างเล็กทุกแถวงาน · เหรียญตราส่งมอบ** (v2.90–2.91) แถวงานในหน้าแรก (งานของฉัน/ต้องจัดการก่อน) · รายการงาน · ภาพรวมบริษัท · ติดตามงาน · ไทม์ไลน์ มีรูปตัวอย่างข้างเลข Job แบบเดียวกับการ์ดบนบอร์ด (มีหลายรูปมีตัวเลขบอก) กดที่รูป = ดูรูปเต็มจอ ไม่เปิดงาน · งานส่งแล้วปลายเส้นความคืบหน้าเป็นเหรียญตรา + ป้าย "ส่งมอบแล้ว"
- **ตั้งแจ้งเตือนสินค้า Express ใกล้หมด** (v2.95 / backend 1.46) ปุ่ม "ตั้งทุกรายการ" ตั้งจำนวนเดียวใช้กับสินค้าทุกตัวทุกหมวดที่ยังมียอด (เช่น เหลือ ≤ 2) พร้อมดูก่อนว่ากี่รายการจะถึงทันที · ปุ่ม "เลือกรายการเอง" ค้นหารหัส/ชื่อ/หมวดแล้วตั้งเฉพาะตัว (ใส่ให้ทั้งหมดที่ค้นเจอได้) · ตั้งเฉพาะชนะค่ารวม · ระบบเช็กทุกชั่วโมง รายการที่เพิ่งลดถึงจุดที่ตั้ง → เด้งแจ้งเตือนมือถือฝ่ายสต็อก 1 ข้อความรวม ไม่เตือนซ้ำ · ตั้งได้เฉพาะฝ่ายสต็อก
- **แจ้งเตือนงานเข้าฝ่ายผลิต / ฝ่ายสต็อก** (v2.89 / backend 1.45) งานใหม่เข้า "รอผลิต" (ออกแบบเสร็จส่งเข้าผลิต หรือเพิ่มเอง) → แจ้งเตือนผู้ใช้ฝ่ายผลิตทุกคน · งานเข้า "พร้อมส่ง" → แจ้งเตือนผู้ใช้ฝ่ายสต็อก · ไม่แจ้งแอดมินและคนที่กดเอง · งานด่วนมีป้าย (ด่วน) · แตะแจ้งเตือนเปิดงานนั้นทันที
- **คีย์เข้า Express อัตโนมัติ** (v2.88) ปุ่ม "คีย์เข้า Express" ในรายการรอลง (ฝ่ายสต็อก) → ตรวจทุกรายการกับยอด Express ก่อน (รหัสมีจริง · คลังมีสินค้า · ยอดในคลังพอ รวมทุกบรรทัด · แผนกมีจริง · ตัวซิงก์ยังทำงาน) รายการไม่ผ่านแจ้งเหตุผลและไม่ส่ง → ส่งเฉพาะที่ผ่านให้ **โปรแกรมช่วยคีย์** (express-sync/KiwNganExpressKey.ps1 ลิงก์ kiwngan-express:) ซึ่งตรวจซ้ำจากไฟล์ Express จริงอีกรอบ แล้วพิมพ์ลงหน้าจอ OU – จ่ายสินค้าใช้ภายใน ทีละใบ (แผนก+Job เดียวกัน = 1 ใบ) · ไม่กดบันทึกให้ คนตรวจแล้วกดบันทึกเอง · ขยับเมาส์ = หยุด · มีโหมดทีละช่อง · ลำดับปุ่มปรับได้ใน config.json (keyRecipe) · ไม่เขียนไฟล์ Express
- **รอลง Express · การ์ดสรุป 6 ใบ** (v2.87 / backend 1.44) เบิก/รับของในแอป (จากการ์ดสินค้า · จากที่เลือกหลายรายการ · จากหน้าคำนวณราคา) ใส่คลัง จำนวน เลข Job แผนก หมายเหตุ → ขึ้นรายการ "รอลง Express" + ป้าย "รอลง ±N" ที่สินค้า + ยอดหลังลงครบ · ฝ่ายสต็อกคัดลอก/พิมพ์รายการไปคีย์ใน Express · เมื่อคีย์แล้วระบบ **จับคู่เลขเอกสารให้อัตโนมัติ** (รหัส ประเภท จำนวนตรงกัน · คีย์รวมหลายรายการเป็นบรรทัดเดียวก็จับได้) · บันทึก ยกเลิก ใส่เลขเอกสารเอง เปิดใหม่: เฉพาะฝ่ายสต็อก (คนอื่นดูและค้นหาได้อย่างเดียว) · สรุปเช้ามี "🧾 รอลง Express" · แอปไม่เขียนอะไรลง Express · การ์ดสรุป: สินค้าทั้งหมด · มีของในคลัง · ใกล้หมด · ยอดติดลบ · รอลง Express · เคลื่อนไหว 7 วัน (กดกรองได้)
- **Express: ดึงครบทุกรหัส · ใกล้หมด · คำนวณราคา** (v2.86 / backend 1.43) แก้บั๊กหน้าแรกดึงสินค้าได้แค่ ~4,000 รหัส (ตอนนี้ครบทุกรหัส แคชเก่าล้างให้อัตโนมัติ) · ตั้ง "จุดสั่งซื้อ" ต่อรหัส (ฝ่ายสต็อก/แอดมิน เก็บในแอป ไม่แตะ Express) → การ์ด/ตัวกรอง/แถบเตือน "ใกล้หมด" · แจ้งในแอปเมื่อยอดลดถึงจุดสั่งซื้อ · สรุปเช้ามีรายการ Express ใกล้หมด · ติ๊กเลือกหลายรายการ (เลือกทั้งหมดที่แสดงได้) → แถบรวมมูลค่า + หน้าคำนวณ: แก้จำนวนได้ (เริ่ม = คงเหลือ) เลือกราคาทุนเฉลี่ย/ซื้อล่าสุด คัดลอก · พิมพ์ · ดาวน์โหลด PDF (แยกปุ่ม v2.87.5) · จำรายการที่เลือกไว้
- **ยอดสต็อกจากโปรแกรม Express** (v2.84 / backend 1.40) หน้าคลังวัสดุมีแท็บ "ยอดจาก Express" แสดงทุกรหัสสินค้าใน Express (ยอดรวม · แยกคลัง · ทุน/หน่วย · ซื้อล่าสุด) ค้นหา กรองตามกลุ่ม/คลัง/ยอดติดลบ · กดดูสต็อกการ์ดทั้งปี · เคลื่อนไหว 7 วันล่าสุด · ไฟเขียว/แดงบอกว่าตัวซิงก์ยังทำงานไหม · ข้อมูลมาจากตัวซิงก์บนเครื่องแม่ข่ายที่ **อ่าน Express อย่างเดียว** แล้วส่งเฉพาะแถวที่เปลี่ยนขึ้น Supabase (ไม่ผ่าน Drive/Sheet) · แอปดึงเฉพาะส่วนที่เปลี่ยน เก็บไว้ในเครื่อง เปิดหน้านี้อยู่อัปเดตทุก 20 วินาที · เห็นเฉพาะผู้มีสิทธิ์ดูสต็อก

- **ธงด่วนติดไปจนส่งมอบ** (v2.60) งานฝ่ายแบบที่ติด "งานด่วน" → งานผลิตเลข Job เดียวกันมีป้าย ด่วน ทุกขั้นจนส่งแล้ว (บอร์ดผลิต การ์ดลอย หน้าต่างรายละเอียด ภาพรวมบริษัท หน้า Sale) · งานด่วนขึ้นก่อนในทุกช่องของบอร์ดผลิต · ฝ่ายผลิตกดติด/เอาออกเองได้ในหน้าต่างงานผลิต (สำหรับงานที่ไม่ได้มาจากฝ่ายแบบ)
- **ประเภทงาน "งาน CAD+CAM"** (v2.59) เขียนแบบและทำ CAM ในงานเดียว (ผ่านรอตรวจเหมือนงานเขียนแบบ) เสร็จแล้วเข้า "รอผลิต" เลย ไม่ถามเปิดงาน CAM ต่อ · กำหนดส่งแนะนำ = วันเขียนแบบ + วัน CAM · เลข Job ที่มีงาน CAD+CAM แล้วเพิ่มงาน CAM ซ้ำไม่ได้ — ตั้งได้ที่ ตั้งค่า > รายการตัวเลือก > รายละเอียดงาน
- **หน้าเข้าสู่ระบบของ Sale แบบใหม่** (v2.59) ปุ่มไล่สีพร้อมเส้นทางงาน ฝ่ายแบบ → ผลิต → ส่งมอบ · ใส่ PIN 4 หลักแบบจุด ครบแล้วเปิดเลย (v2.60: PIN ของ Sale เป็น 4 หลัก) · PIN ผิดสั่นเตือน · เมนูล่างมือถืออยู่แถวเดียวเสมอ (เมนูเยอะเลื่อนซ้าย-ขวาได้)
- **สิทธิ์แบบช่องติ๊ก** (v2.56) แอดมินกด "สิทธิ์" ที่แถวผู้ใช้ (ตั้งค่า > ผู้ใช้งานและสิทธิ์) แล้วติ๊กเปิด/ปิดทีละเรื่อง: ลงงานใหม่ · แก้ไขงานของคนอื่น · มอบหมายงาน · ลบงานของคนอื่น · อัปเดตบอร์ดผลิต · กด "ส่งแล้ว" · ดูคลังวัสดุ · จัดการคลังวัสดุ · ดูผลงานทุกคน — ตำแหน่งเป็นตัวกำหนดค่าเริ่มต้น (มีตารางสรุปในหน้าเดียวกัน) หลังบ้านตรวจซ้ำทุกคำขอ
- **ฝ่ายสต็อก** (v2.56) ตำแหน่งใหม่ "พนักงาน · ฝ่ายสต็อก" ฝ่ายผลิตทำได้ถึง "พร้อมส่ง" แล้วฝ่ายสต็อกเป็นคนกด **ส่งแล้ว** ปิดงานขั้นสุดท้าย (ย้อนกลับเป็นพร้อมส่งได้)
- **คลังวัสดุแบบการ์ดมีรูป** (v2.57, สีสันและแอนิเมชัน v2.58) การ์ดวัสดุพร้อมรูปปก สถานะ (พร้อมใช้ / ใกล้หมด / หมดสต็อก) แถบระดับคงเหลือเทียบจุดสั่งซื้อ ปุ่มรับเข้า/เบิกบนการ์ด · กดการ์ดเปิดหน้าต่างรายละเอียด: รูปทั้งหมด รับเข้า/เบิกออก/ปรับยอดพร้อมปุ่ม − + ประวัติของวัสดุชิ้นนั้น · **ใส่รูปสินค้าได้ 8 รูป: เลือกไฟล์ หรือกด "ถ่ายรูป"** (คอมใช้เว็บแคมในหน้าต่าง มือถือใช้กล้องหลัง) เก็บใน Drive โฟลเดอร์ `รูปงาน/คลังวัสดุ` · ปุ่ม + ลอยมุมขวาล่างเปิดหน้าต่างเพิ่มวัสดุเหมือนแผนกอื่น (เลือกหมวด/หน่วยด้วยปุ่ม ใส่รูปได้ตั้งแต่ตอนเพิ่ม)
- **คลังวัสดุ** (v2.56) รายการวัสดุ ยอดคงเหลือ จุดสั่งซื้อ ที่เก็บ · รับเข้า / เบิกออก (ระบุเลข Job ได้) / ปรับยอดตอนนับสต็อก · รายการใกล้หมดขึ้นก่อนและมีตัวเลขเตือนที่เมนู · ประวัติการเคลื่อนไหวทั้งหมด (ชีต `Stock`, `StockLog` สร้างให้เอง)
- **ภาพรวมบริษัท** (v2.26) ทุกเลข Job ในสายเดียว: ฝ่ายแบบ → รอผลิต → ลงเครื่อง → ทำสี → ประกอบติดตั้ง → แพ็ค → พร้อมส่ง → ส่งแล้ว กดขั้นเพื่อกรอง แล้วเลื่อนลงไปที่รายการงานของขั้นนั้นให้เอง (v2.76.1 · หน้า Sale ด้วย) เห็นงานค้างนานทันที · **ทุกคนเห็นงานทั้งหมดของระบบ แต่แก้ไขได้เฉพาะงานของตัวเอง** (v2.56)
- **บอร์ดฝ่ายผลิต** งานประเภทที่ "ส่งผลิต" (ค่าเริ่มต้น: ชื่อมีคำว่า CAM) ทำเสร็จแล้วเข้า "รอผลิต" เอง · เลือกเครื่องได้หลายเครื่อง (Router / Laser / Punching / WaterJet แก้รายชื่อได้ในตั้งค่า) ติ๊กเครื่องที่เสร็จ ครบแล้วไปทำสีเอง → ประกอบติดตั้ง (v2.27) → แพ็ค · ข้ามทำสีหรือประกอบได้ · ย้อนขั้นได้ · ประวัติทุกขั้น · กรองตามเครื่อง
- **ตำแหน่ง "ฝ่ายผลิต"** เห็นภาพรวมบริษัท บอร์ดผลิต ทีมงาน และตั้งค่า · อัปเดตงานผลิตได้ (หัวหน้างาน/แอดมินก็ได้) · ฝ่ายแบบดูงานผลิตได้อย่างเดียว
- **การ์ดลอยมีเช็กลิสต์และคอมเมนต์** (v2.28) ชี้เมาส์ที่งานแล้วเห็นเช็กลิสต์ (ทำไปกี่ขั้น ใครติ๊ก) และคอมเมนต์ล่าสุด 3 ข้อความด้านขวา
- **หน้า Sale แบบภาพรวมสถานะ** (v2.33) หน้าตาเหมือนภาพรวมบริษัท: สายงานฝ่ายแบบ → ผลิต → ส่งมอบ 1 แถวต่อเลข Job กดแถวเพื่อดูงานฝ่ายแบบ ขั้นผลิต และหมายเหตุ · สลับไปตารางแบบเดิมได้
- **ปุ่ม Sale ที่หน้าเข้าสู่ระบบ** แอดมินตั้ง PIN ของ Sale ที่ ตั้งค่า > Sale แล้ว Sale กดปุ่ม ใส่ PIN ก็เห็นหน้าสถานะงาน (มีขั้นผลิตด้วย)
- **บอร์ดงาน** ลากการ์ดเปลี่ยนสถานะ: รอคิว → กำลังทำ → รอตรวจ/แก้ → เสร็จแล้ว (มีสถานะ "พักไว้")
- **สีแยกงาน** การ์ดและรายการงานมีสีตาม "รายละเอียดงาน" (ทำ CAD / ทำ CAM / …) และป้ายสีตามกลุ่มงาน (2D / 3D / …) — แอดมินเลือกสีเองได้ที่ ตั้งค่า > รายละเอียดงาน
- **ลำดับงาน** การ์ดแต่ละช่องมีเลขลำดับ 1, 2, 3 ตามคิว
- **งาน CAM ไม่ต้องรอตรวจ** กดเลื่อนหรือลากจาก "กำลังทำ" แล้วไป "เสร็จแล้ว" ทันที
- **อีโมจิในข้อความ** ปุ่ม 😊 ในห้องแชท จำอีโมจิที่ใช้ล่าสุดให้
- **จับเวลาทำงานต่อชิ้น** กดเริ่ม/หยุดได้หลายรอบ ระบบรวมเวลาให้ และแสดงแถบจับเวลาตลอดเวลา
- **กำหนดส่งอัตโนมัติ** คำนวณจากกลุ่มงาน + ประเภทงาน + จำนวนชิ้น (ตั้งค่าตารางวันมาตรฐานเองได้ ไม่นับเสาร์-อาทิตย์)
- **ภาพรวม** งานค้าง, เลยกำหนด, งานด่วน, % ตรงเวลา, กราฟงานเสร็จ 30 วัน, ภาระงานรายคน
- **รายการงาน** ค้นหา กรอง และส่งออก CSV (เปิดใน Excel ได้ ภาษาไทยไม่เพี้ยน)
- **ทีมงาน** งานค้าง/เสร็จ/ตรงเวลา/ชั่วโมงทำงานของแต่ละคน และใครกำลังทำงานอะไรอยู่
- **ประวัติงาน** ใครเปลี่ยนสถานะหรือแก้ไขอะไร เมื่อไร
- **สรุปรายงาน + สั่งพิมพ์** เลือกช่วงเวลา (วันนี้/สัปดาห์/เดือน/ปี/กำหนดเอง) คน และกลุ่มงาน ได้สรุปตัวเลข สรุปรายคน สรุปตามกลุ่มงาน รายการงาน และช่องลงชื่อ พิมพ์ A4 แนวตั้ง/แนวนอน หรือบันทึกเป็น PDF
- **ผู้ใช้และสิทธิ์** เข้าสู่ระบบด้วยชื่อ + PIN แยกสิทธิ์แอดมินกับผู้ใช้งาน ตรวจสิทธิ์ที่ฝั่งเซิร์ฟเวอร์
- **ตำแหน่ง** พนักงาน / หัวหน้างาน / ผู้ดูแลระบบ มีไอคอนแสดงตำแหน่ง หัวหน้างานดูผลงานทุกคนในหน้าทีมงานและสรุปรายงานของทุกคนได้ (แก้ไขงานได้เฉพาะของตัวเองเหมือนพนักงาน)
- **แชร์หน้าจอ / รีโมท** ในห้องแชทส่วนตัว: "ขอดูจอ" ของอีกฝ่าย, "แชร์จอฉัน" ให้อีกฝ่ายดู และ "รีโมท" ให้คนดูชี้ (เลเซอร์) หรือวาดวงบนภาพ คนแชร์เห็นตามทันทีในกรอบมุมจอหรือ "หน้าต่างลอย" ที่อยู่บนสุดทับโปรแกรมอื่น — ไม่ต้องติดตั้งโปรแกรมใดๆ (ภาพและเส้นวิ่งตรงระหว่างเครื่องแบบ WebRTC ไม่ผ่านเซิร์ฟเวอร์ ต้องกดอนุญาตทุกครั้ง แชร์หน้าจอได้จากคอมพิวเตอร์ ส่วนมือถือที่เบราว์เซอร์แชร์หน้าจอไม่ได้จะ "แชร์กล้อง" แทน (สลับกล้องหน้า/หลังได้) ดูและชี้ได้ทุกคู่: คอม↔มือถือ, มือถือ↔มือถือ หน้าต่างลอยใช้ได้ใน Chrome/Edge)
- **โทรหากัน (เสียง)** ปุ่ม "โทร" ในห้องแชทและการ์ดทีมงาน มีเสียงเรียกเข้า/รอสาย ปิดไมค์/ลำโพงได้ ไม่มีคนรับจะส่งข้อความแจ้งสายที่ไม่ได้รับ · **แจ้งเตือนสายเรียกเข้าแม้ปิดแอป** (Web Push) เปิดได้ที่ ตั้งค่า > แจ้งเตือนสายเรียกเข้า (iPhone ต้องติดตั้งแอปลงหน้าจอโฮมก่อน) — backend ลงนาม VAPID (ES256) เอง ไม่ต้องใช้บริการภายนอก
- **ห้องเสียงทีม (แบบ Discord)** เข้าห้องที่หน้าทีมงานหรือแชท "ทั้งทีม" คุยพร้อมกันหลายคน เปิด/ปิดไมค์ ปิดเสียงห้อง เห็นว่าใครกำลังพูด (วงเขียว) และแชร์จอ/กล้องให้ทั้งห้องดู — ทุกเครื่องต่อตรงหากัน (mesh) เหมาะกับทีม ~2–8 คน ฐานข้อมูลเก็บแค่รายชื่อคนในห้อง
- **รูปโปรไฟล์** ทุกคนใส่รูปตัวเองได้ที่ ตั้งค่า > บัญชีของฉัน แอดมินใส่/ลบรูปให้ทุกคนได้ (ย่อเหลือ 160px อัตโนมัติ เก็บในชีต)
- **รูปงาน** ลากรูปมาวาง / วางจากคลิปบอร์ด (Ctrl+V) ได้ตั้งแต่หน้าเพิ่มงาน แนบรูปได้สูงสุด 8 รูปต่องาน (ย่อขนาดให้อัตโนมัติ) เก็บเป็นไฟล์ใน Google Drive โฟลเดอร์ `รูปงาน/<เลข Job>` ชีตเก็บแค่รายการ กดดูแบบเต็มจอ เลื่อนดูรูปถัดไปได้
- **CAD เสร็จ → เปิดงาน CAM ต่อคลิกเดียว** เลื่อนงาน CAD เป็น "เสร็จแล้ว" ระบบถามว่าจะเปิดงาน CAM ต่อไหม กด "เปิดงาน CAM" ได้งานใหม่เลข Job เดิม พร้อมรายละเอียดและรูปเดิม
- **เก็บทุกอย่างไว้ที่โฟลเดอร์เดียวใน Drive** (โฟลเดอร์เดียวกับชีตฐานข้อมูล) มีโฟลเดอร์ย่อย `รูปงาน`, `สำรองข้อมูล (อัตโนมัติ)`, `เก็บถาวร (งานเก่า)`, `เอกสาร / ไฟล์งานอื่นๆ`
- **สำรองข้อมูลทุกคืน** ตี 2 คัดลอกชีตไว้ในโฟลเดอร์สำรอง เก็บย้อนหลัง 30 วัน
- **เก็บงานเก่าอัตโนมัติ** ทุกวันที่ 1 ย้ายงานที่เสร็จเกิน 12 เดือน (พร้อมเวลา รูป ประวัติ ข้อความเก่า) ไปไฟล์ "เก็บถาวร" ชีตหลักจึงเร็วตลอด หน้าสรุปรายงานยังดึงงานเก่ามาคิดให้อัตโนมัติ
- **แจ้งเตือนงาน** มีคนมอบงานให้ / งานถูกส่งกลับมาแก้ / สรุปงานที่ครบกำหนดพรุ่งนี้ (แจ้งบนจอและ Web Push ทุกเช้าวันทำงาน 8 โมง)
- **ไฟล์งาน** แนบ DWG, DXF, NC, PDF ฯลฯ (ไม่เกิน 30 MB) ในหน้ารายละเอียดงาน เก็บใน Drive โฟลเดอร์ `ไฟล์งาน/<เลข Job>` ดาวน์โหลด/ลบได้
- **เช็กลิสต์ในงาน** ติ๊กทีละขั้น เห็นความคืบหน้าบนการ์ด ตั้ง "เช็กลิสต์มาตรฐาน" ต่อรายละเอียดงานได้ งานใหม่จะได้เช็กลิสต์อัตโนมัติ
- **คอมเมนต์ในงาน** คุยใต้งานนั้นเลย แจ้งเตือนผู้รับผิดชอบ/ผู้ร่วมทำงาน
- **ผู้ร่วมทำงาน** เพิ่มคนช่วยในงานได้หลายคน ทำงาน/จับเวลาได้เหมือนผู้รับผิดชอบ
- **ตารางงานรายคน** (หน้าภาพรวม สำหรับหัวหน้า/แอดมิน) เห็นว่าใครทำอะไรช่วงไหน งานไหนเป็นงานที่ไปช่วย
- **วันหยุดบริษัท** ไม่นับเป็นวันทำการตอนคำนวณกำหนดส่ง มีปุ่มเพิ่มวันหยุดราชการที่วันที่ตายตัว
- **ลิงก์ดูสถานะงานสำหรับ Sale** หน้าอ่านอย่างเดียว ไม่ต้องเข้าสู่ระบบ แยกตาม Sale (ตั้งค่า > ลิงก์สำหรับ Sale)
- **Realtime (Supabase ฟรี)** โทร แชร์จอ และข้อความ ส่งสัญญาณผ่าน Supabase Realtime แบบเข้ารหัส (AES-GCM) เร็วกว่าเดิมมาก ถ้าเชื่อมไม่ได้จะกลับไปใช้ Apps Script อัตโนมัติ
- **ดูข้อมูลงานเร็ว** กดที่งานเพื่อดูรายละเอียด สถานะ รูป และประวัติ หรือเอาเมาส์ชี้ค้างไว้เพื่อดูสรุป รูปแสดงใหญ่ด้านบน กดดูเต็มจอได้ทันที (กดรูปเล็กบนการ์ดก็เปิดดูได้เลย)
- **ข้อความและขอความช่วยเหลือ** คุยกับทั้งทีม แอดมิน หรือรายคน กด "ขอช่วย" เพื่อขอความช่วยเหลือ (ระบุเรื่องและงานได้) ใครว่างกด "ฉันช่วยได้" มีแจ้งเตือนเด้งจากด้านข้าง เสียง และแจ้งเตือนบนเครื่อง
- **White-label** เปลี่ยนชื่อบริษัท ชื่อระบบ สี และโลโก้ได้จากหน้าตั้งค่า
- **ธีมส่วนตัว** ทุกคนเลือกเทมเพลตสี 9 แบบหรือกำหนดสีเอง โหมดสว่าง/มืด/ตามเครื่อง เมนูข้างสีไล่หรือพื้นเรียบ หัวเพจ 3 แบบ และมุมโค้ง/เหลี่ยม ได้ที่ ตั้งค่า > ธีมและสี (เก็บแยกในแต่ละเครื่อง)
- **โหมดทดลอง** ใช้งานได้ทันทีโดยไม่ต้องต่อชีต (ข้อมูลเก็บในเบราว์เซอร์นั้น)

## ติดตั้ง

### 1. เปิดหน้าเว็บด้วย GitHub Pages
repo นี้ > **Settings > Pages** > Source: **Deploy from a branch** > Branch: `main` / `(root)` > Save
รอ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/KiwNgan/`

### 2. สร้างฐานข้อมูล (Google Sheet + Apps Script)
1. สร้าง Google Sheet ใหม่ (ตั้งชื่อเช่น "KiwNgan – ชื่อบริษัท")
2. **ส่วนขยาย > Apps Script** ลบโค้ดเดิม แล้ววางเนื้อหาไฟล์ `backend/Code.gs`
3. เลือกฟังก์ชัน `setup` ในแถบด้านบน แล้วกด **เรียกใช้** > อนุญาตสิทธิ์
   ระบบจะสร้างชีต `Jobs`, `TimeLogs`, `Activity`, `Users`, `Settings` และบัญชี **แอดมิน** พร้อม PIN 4 หลัก (ดูในบันทึกการดำเนินการ)
4. **ทำให้ใช้งานได้ > การทำให้ใช้งานได้รายการใหม่ > ประเภท: เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
5. คัดลอก URL ที่ลงท้ายด้วย `/exec`

> ทุกคำขอต้องเข้าสู่ระบบก่อน (ยกเว้นรายชื่อผู้ใช้บนหน้าเข้าสู่ระบบ) ถ้าแอดมินลืม PIN ให้เรียกฟังก์ชัน `resetAdminPin` แล้วดู PIN ใหม่ในบันทึกการดำเนินการ

### 3. เชื่อมต่อและเข้าสู่ระบบ
1. เปิดเว็บ > หน้าเข้าสู่ระบบ > **เชื่อมต่อ Google Sheet ของทีม** > วาง URL > **เชื่อมต่อ**
2. กด **ผู้ดูแลระบบ** ที่ด้านล่าง > ใส่ชื่อ `แอดมิน` และ PIN จากขั้นที่ 2
3. ไปที่ **ตั้งค่า > ผู้ใช้งานและสิทธิ์** เปลี่ยนชื่อแอดมินเป็นชื่อจริง และเพิ่มคนในทีม (ระบบจะแสดง PIN ของแต่ละคนให้แจ้งเจ้าตัว)
4. กด **คัดลอกลิงก์เข้าใช้งานให้ทีม** ในหน้าตั้งค่า แล้วส่งให้ทีม ลิงก์นี้จะเชื่อมต่อฐานข้อมูลให้อัตโนมัติ

## ผู้ใช้และสิทธิ์

สิทธิ์เริ่มต้นตามตำแหน่ง (แอดมินติ๊กเพิ่ม/ลดให้รายคนได้):

| สิทธิ์ | พนักงาน ฝ่ายแบบ | หัวหน้างาน ฝ่ายแบบ | พนักงาน ฝ่ายผลิต | พนักงาน ฝ่ายสต็อก | แอดมิน |
|---|---|---|---|---|---|
| ลงงานใหม่ | ✓ | ✓ | – | – | ✓ |
| แก้ไขงานของคนอื่น | – | – | – | – | ✓ |
| มอบหมายงานให้คนอื่น | – | – | – | – | ✓ |
| ลบงานของคนอื่น | – | – | – | – | ✓ |
| อัปเดตบอร์ดผลิต (ถึงพร้อมส่ง) | – | – | ✓ | – | ✓ |
| กด "ส่งแล้ว" | – | – | – | ✓ | ✓ |
| ดูคลังวัสดุ | ✓ | ✓ | ✓ | ✓ | ✓ |
| จัดการคลังวัสดุ | – | – | – | ✓ | ✓ |
| ดูผลงานทุกคน / รายงานทุกคน | – | ✓ | – | – | ✓ |

ทุกตำแหน่งเห็นงานทั้งหมดในภาพรวมบริษัท และแก้ไข/จับเวลางานที่ตัวเองรับผิดชอบ ลงเอง หรือเป็นผู้ร่วมทำงานได้

| | แอดมิน | ผู้ใช้งาน |
|---|---|---|
| ดูบอร์ดและรายการงานของทั้งทีม | ✓ | ✓ |
| ลงงานใหม่ | ✓ มอบหมายให้ใครก็ได้ | ✓ เป็นงานของตัวเอง |
| แก้ไข / เปลี่ยนสถานะ | ทุกงาน | งานที่ตัวเองรับผิดชอบหรือเป็นคนลง |
| จับเวลา | ทุกงาน | งานของตัวเอง |
| ลบงาน | ทุกงาน | งานที่ตัวเองเป็นคนลง |
| จัดการผู้ใช้ / รีเซ็ต PIN | ✓ | – |
| ตั้งค่า แบรนด์ รายการตัวเลือก | ✓ | – |
| เปลี่ยน PIN ของตัวเอง | ✓ | ✓ |

- **ฝ่ายผลิต** (ตำแหน่ง "ฝ่ายผลิต" แอดมินเพิ่มได้ที่ ตั้งค่า > ผู้ใช้งานและสิทธิ์) และแอดมิน เพิ่ม/อัปเดต/ลบงานบนบอร์ดผลิตได้ · ตำแหน่งอื่นดูบอร์ดผลิตได้อย่างเดียว · ฝ่ายผลิตดูงานฝ่ายแบบได้ทั้งหมดแต่เพิ่ม/แก้ไม่ได้ · คุยกันในหน้าข้อความได้ตามปกติ
- **ชื่อแอดมินไม่แสดงให้ผู้ใช้งานเห็น** ทั้งในหน้าเข้าสู่ระบบ รายชื่อทีม และประวัติงาน (แสดงเป็น "ผู้ดูแลระบบ") แอดมินเข้าสู่ระบบผ่านลิงก์ "ผู้ดูแลระบบ" โดยพิมพ์ชื่อ + PIN
- ผู้ใช้งานไม่เห็นข้อมูลการเชื่อมต่อฐานข้อมูล
- ใส่ PIN ผิด 5 ครั้งจะล็อก 10 นาที (แอดมินรีเซ็ต PIN ให้ได้)
- เข้าสู่ระบบครั้งหนึ่งอยู่ได้ 30 วันต่อเครื่อง
- ปิด "ใช้งาน" ของผู้ใช้ = ระงับทันทีทุกเครื่อง โดยประวัติงานยังอยู่ครบ
- ฟังก์ชัน `logoutEveryone` ใน Apps Script ใช้บังคับออกจากระบบทุกเครื่อง

### 4. ติดตั้งลงมือถือ
- iPhone: เปิดใน Safari > ปุ่มแชร์ > **เพิ่มไปยังหน้าจอโฮม**
- Android: เปิดใน Chrome > เมนู ⋮ > **ติดตั้งแอป**

## ย้ายข้อมูลจากชีต "ตารางงานแบบ Jobshop" เดิม
1. ใน `Code.gs` ใส่ ID ของชีตเดิมในบรรทัด `const OLD_SHEET_ID = ''`
   (ID คือส่วนกลางของลิงก์ชีต `docs.google.com/spreadsheets/d/<ID>/edit`)
2. เลือกฟังก์ชัน `importJobshop` > **เรียกใช้**
   ระบบจะนำเข้างานจากชีต `Task View` พร้อม sale, กลุ่มงาน, เวลาเริ่ม-จบ และสร้างบัญชีผู้ใช้ให้ทีมงานทุกคน (PIN ของแต่ละคนอยู่ในบันทึกการดำเนินการ) งานที่มีเลข Job ซ้ำจะข้าม

## ความเร็ว (v2.11 / backend 1.11)
- หน้าเว็บเช็กทุก ~5 วินาทีแบบเบามากว่ามีงานหรือข้อความเปลี่ยนไหม แล้วดึงข้อมูลเฉพาะตอนที่เปลี่ยน — เครื่องอื่นแก้งานแล้วเห็นภายในไม่กี่วินาที
- backend จำข้อมูลผู้ใช้ การตั้งค่า รูปย่อ และรูปเต็มไว้ใน cache ไม่ต้องอ่านชีตทุกคำขอ
- แก้ไขงานเดิมแล้วกดบันทึก หน้าต่างปิดทันที ระบบบันทึกเบื้องหลัง (ถ้าไม่สำเร็จจะเปิดฟอร์มคืนพร้อมข้อความเดิม)
- ถ้าแก้ข้อมูลในชีตด้วยมือ หน้าเว็บจะเห็นภายใน 5 นาที

## ทางด่วนคำตอบ (v2.18 / backend 1.17)
ประตู `script.googleusercontent.com` ของ Google ชอบค้าง 5–30 วิ ทั้งที่โค้ดทำงานเสร็จใน 1–2 วิ จึงให้ Apps Script ส่งคำตอบตรงไปที่ "กล่องรับ" ของแต่ละเครื่องผ่าน Supabase Realtime ด้วย (ชื่อกล่องสุ่ม เปลี่ยนทุกครั้งที่เปิดแอป) แอปใช้คำตอบที่มาถึงก่อน
- เข้าสู่ระบบส่งข้อมูลเริ่มต้นกลับมาในคำขอเดียว (ไม่ต้องเรียก bootstrap ซ้ำ) และไม่ล็อกชีต
- หน้าเข้าสู่ระบบแสดงรายชื่อที่จำไว้ทันที แล้วค่อยอัปเดตเบื้องหลัง

## Drive, สำรองข้อมูล และ Realtime (backend 1.16)
1. เลือกฟังก์ชัน `setupAll` > **เรียกใช้** > อนุญาตสิทธิ์ (Drive, ทริกเกอร์, เชื่อมต่อภายนอก) — ครั้งเดียวพอ
   ระบบจะสร้างโฟลเดอร์ย่อย ไฟล์เก็บถาวร ตั้งทริกเกอร์ `nightly` (ตี 2) และ `morningReminders` (8 โมง) สำรองข้อมูลครั้งแรก และย้ายรูปเดิมจากชีตไป Drive (ถ้ารูปเยอะเกินเวลา ให้กด `migrateImagesToDrive` ซ้ำจนขึ้นว่า "ครบแล้ว")
2. Realtime: ใส่ `RT_URL` และ `RT_KEY` (publishable key) ของโปรเจกต์ Supabase ใน `Code.gs` (ไม่ต้องสร้างตาราง ใช้แค่ Broadcast) — ว่างไว้ = ใช้ Apps Script อย่างเดียว
3. ฟังก์ชันเรียกเองได้: `backupNow`, `archiveOld` (ค่าเริ่มต้น 12 เดือน)
